# Triage Labels

The engineering skills use five canonical triage roles. This table maps those roles to the labels used by the Linear team.

| Canonical role    | Linear label      | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate this issue           |
| `needs-info`      | `needs-info`      | Waiting for more information from the reporter    |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `needs-human`     | Requires human implementation or judgment         |
| `wontfix`         | `wontfix`         | Will not be actioned                              |

When a skill refers to a canonical role, use the corresponding Linear label.
