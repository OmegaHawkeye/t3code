# Domain Docs

This repository is a multi-context monorepo. Before exploring a domain, read the root `CONTEXT-MAP.md` if present, then read the relevant context files and area-specific ADRs. Read system-wide decisions in `docs/adr/` when present. If those files do not yet exist, proceed silently; create them only when domain modeling work establishes a durable need.

Use the domain's established vocabulary in issues, proposals, and tests. Surface conflicts with documented decisions instead of silently overriding them.
