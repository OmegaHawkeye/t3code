# Issue tracker: Linear

Linear is the source of truth for issues in this repository. Use the connected Linear tools to fetch tickets and make requested updates. The relevant project is **Local Linear Agent Runner** and its tickets use the `OME` identifier prefix.

## Conventions

- Fetch the referenced Linear issue before starting ticket work.
- Keep issue status and acceptance criteria current when the task explicitly calls for a Linear update.
- Do not create GitHub issues or treat external GitHub pull requests as incoming triage work.
- Do not create a pull request unless the maintainer explicitly asks for one.
